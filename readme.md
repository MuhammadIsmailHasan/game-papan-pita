# Ismail By Erris Framework

## Library yang digunakan:

1. appzcoder/laravel-admin
2. intervention/image
3. maatwebsite/excel
4. owen-it/laravel-auditing
5. rap2hpoutre/laravel-log-viewer
6. tymon/jwt-auth
7. barryvdh/laravel-debugbar

## Cara Penggunaan:

1. Buat file .env (ambil dari .env.example)
2. Ganti setting mysql
3. Jalankan docker
4. Jalankan command "composer update"
5. Migrate database dan seeder
6. jalankan command "php artisan key:generate"
7. jalankan command "php artisan jwt:secret"

### Note:
1. Pastikan untuk menambahkan auditable di setiap model yang digunakan
